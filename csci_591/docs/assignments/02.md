# Assignment 02: Fuzzing

## Description

Write a fuzzer which utilizes grammars or templates and mutations to generate session input for an SMTP server.

SMTP (Simple Mail Transfer Protocol) is a protocol used to send email messages. An SMTP server with several intentional (and maybe some unintentional) vulnerabilities is provided as your target.

The fuzzer may be written in any programming language.

### Target Information

`voidsmtpd` is a new SMTP daemon that accepts message from an email client. It has been built for Linux 64-bit x86 (amd64) and macOS Apple Silicon and the program source code is unavailable.

The daemon prints log output to `stdout` and can be used to understand the state of the program. The daemon was built with address sanitizer enabled and the program will crash if a buffer overflow or out-of-bounds access is detected.

`voidsmtpd` by default listens for connections on port 2525, however a different port can be specified by providing a port number as an argument:
``` console
➜ ./voidsmtpd 2050
Server listening on port 2050
```

A special implementation detail of `voidsmtpd` is that it stores accepted emails from clients in a ring buffer. Emails are not sent immediately upon receipt but are instead placed in the ring buffer queue to be sent asynchronously. Please note this test release of `voidsmtpd` does not actually send emails.

## Submissions

Please provide your the source code for your fuzzer, build instructions, and the input and log files of any successful, unique crashes.

Submissions should be provided as a ZIP file through Brightspace.

## Grading

The assignment will be graded based on:

- (70%) A fuzzer capable of generating unique, random inputs that roughly follow the SMTP specification
- (15%) A log, with input, containing *at least one* crash of the SMTP server with fuzzer-generated input and server crash messages
- (5%) Logs, with inputs, containing *three* crashes which indicate three different crash sites/potential vulnerabilities
- (10%) A brief report describing any discovered crashes and their potential causes
