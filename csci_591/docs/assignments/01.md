# Assignment 01: Software Vulnerabilities

## Description
Write two programs, each which contain one intentional vulnerability that you introduced. The vulnerabilities should be from different vulnerability classes.

You may write the programs in any language of your choosing and you may use a different language for each program.

The vulnerabilities you include in your programs should be from one of the following vulnerability classes:

- Integer overflow
- Buffer overflow (stack- or heap-based)
- Out of bounds access (read or write)
- Command injection
- Use after free
- Path traversal

Definitions of those vulnerabilities and more can be found at the [Common Weakness Enumeration (CWE) website](https://cwe.mitre.org/index.html). The Search CWE feature can be used to lookup types of vulnerabilities by name.

Each group will present their vulnerable code in class and answer questions about how the vulnerabilities work and what behavior they enable.

If desired, you may include demo user input as a part of your program. Be careful to mark any simulated user data or interactions in your program so it is clearly distinct from the vulnerability itself.

Presentations should be 10&#8211;15 minutes long and presentation of the material will be followed by approximately 5 minutes of questions. Be prepared to answer technical questions about your selected vulnerability classes and examples which demonstrate your understanding. Questions will be asked of every group member.

## Submissions
Submissions should include examples of at least two different classes of vulnerabilities. For each vulnerability, please provide either example input or a demo script which can be used to exercise the vulnerability.

Submissions should be provided as a ZIP file through Canvas.

## Grading
The assignment grade will be based on:

- Two examples of different vulnerability classes (30%)
- Program input/demo script of vulnerabilities being exercised (30%)
- Presentation of the vulnerabilities for class discussion (40%)
